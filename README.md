# Real-Time Macroeconomic Data Pipeline & Dashboard

An end-to-end quantitative data science pipeline that extracts real-time macroeconomic indicators from public APIs, stores them in a local relational database, and exposes an interactive analytics dashboard.

## Tech Stack
- **Language:** Python
- **Data Engineering:** Pandas, Requests, SQLite3
- **Visualization & Dashboard:** Streamlit, Plotly
- **Environment & Version Control:** Virtualenv, Git
